Engine inventory artwork
=======================

Generated with the built-in imagegen tool. These are original game equipment
illustrations inspired by 24th-century Federation propulsion hardware, not named
canonical engine models. The three PNGs are used directly by Inventory and the
port Equipment shop, with no dependency on a developer's generated-image folder.
The visual reference is the nacelles, collectors and illuminated warp grilles
shown by the [official Enterprise-D replica](https://shop.startrek.com/products/star-trek-the-next-generation-u-s-s-enterprise-ncc-1701-d-bluetooth-speaker-with-sleep-machine-led-s-sound-effects).

Shared prompt:

Use case: stylized-concept. Asset type: square equipment icon for Vexed Mirror Star Trek inventory. Create one centered isolated detailed 3D engineering module, a compact Federation 24th-century warp propulsion assembly with paired nacelle-like warp-coil housings, blue warp plasma coils and red Bussard collector caps, pale titanium plating, charcoal structure, believable Star Trek hardware rather than a spaceship. Three-quarter isometric product render, strong clean silhouette readable at 64 pixels, rich controlled cinematic lighting, near-black navy background, object fills 85% of square, no writing, no border, no UI, no watermark. 

Variants:

- Standard: simple robust twin housings, four bright blue coil segments,
  restrained industrial design.
- Upgraded: sleeker twin swept housings, six blue coil segments and small amber
  regulator, distinctly more refined but same hardware family.
- Advanced: premium curved twin housings, eight intense cyan blue coil segments,
  central luminous dilithium regulator, most sophisticated model in same family.
