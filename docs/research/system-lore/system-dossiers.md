# Planetary system dossiers

All 52 current map destinations retain their existing IDs. Original full game descriptions, population/ownership fields, artwork references, station coordinates, and explicit Rebirth matches are archived in [systems.json](systems.json). A source-backed body entry may be a moon, star, station, duplicate designation, or disputed candidate; it is not a count of additional planets.
